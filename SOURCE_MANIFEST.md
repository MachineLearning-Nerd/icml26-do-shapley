# Source and artifact manifest

## Paper provenance

- Primary paper: [arXiv:2602.07203](https://arxiv.org/abs/2602.07203), v1.
- Review record: [OpenReview Peim0KY6ty](https://openreview.net/forum?id=Peim0KY6ty).
- `docs/paper.txt`: local text extraction used as a convenient, reviewable
  reference while writing the clean-room implementation.
- No official source repository, model checkpoint, or external dataset is
  included in this reproduction.

## Repository files

| `outputs/*.csv` | committed finite experiment tables | generated by `run_claims.py` |
| `outputs/summary.json` | aggregate metrics and verdict inputs | generated by `run_claims.py` |
| `verify_final.py` | release and fresh-clone verifier | repository audit tooling |

## Reproducibility boundary

The output tables are committed evidence from the recorded producer run. The
producer measures wall-clock time, so timing values can vary across machines;
the verifier checks structural and numerical thresholds rather than requiring
identical runtimes. Re-running the producer may update timing fields and should
be reviewed as a new evidence run.

This repository is an independent reproduction, not an author-endorsed release
of the paper's code.
